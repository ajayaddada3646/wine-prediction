# 🍷 Wine Quality Prediction with Spark ML

This project predicts wine quality using a logistic regression model trained with Apache Spark MLlib. It is implemented in Java and packaged using Docker for reproducibility and scalability.

---

## 🚀 Technologies Used

- Apache Spark MLlib
- Java (Maven project)
- Logistic Regression
- Docker
- MulticlassClassificationEvaluator
